# ResearchGPT Frontend

## Overview

Modern React-based UI for ResearchGPT with TypeScript, TailwindCSS, and Vite.

## Features

- 🎨 **Modern UI** - Responsive design with TailwindCSS
- ⚡ **Fast Development** - Vite for instant HMR
- 📱 **Mobile Friendly** - Works on all devices
- 🔍 **Real-time Search** - See research in action
- 📊 **Rich Results** - Beautiful result display
- ♿ **Accessible** - WCAG compliant

## Setup

```bash
cd frontend
npm install
npm run dev
```

## Build

```bash
npm run build
```

## Production

```bash
npm run preview
```

## Components

- **App.tsx** - Main application component
- **SearchForm.tsx** - Research input form
- **ResultsDisplay.tsx** - Results visualization
- **LoadingSpinner.tsx** - Loading state UI
- **SourcesList.tsx** - Source references

## Styling

Using TailwindCSS for utility-first styling with custom animations.

## API Integration

Connects to ResearchGPT API at `http://localhost:8000/api`

## Browser Support

- Chrome (latest)
- Firefox (latest)
- Safari (latest)
- Edge (latest)
